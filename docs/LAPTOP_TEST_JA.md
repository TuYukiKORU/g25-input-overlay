# F1 Telemetry — はじめに

同梱の **manual-ja.html**（日本語）と **manual-en.html**（英語）は、オフラインで読める完全なユーザーマニュアルです。印刷／PDF保存に対応し、各ページ・記録・比較の根拠・バックアップ・不具合対応を説明します。アプリ上部の **ユーザーマニュアル** からも開けます。負荷測定の詳細は **PERFORMANCE.md**、日本語の概要はマニュアルの「ゲーム中の負荷」を参照してください。

Windows x64向け・日本語／English切り替え対応のテスト版です。

0.3.1-laptop-previewでは、選択ラップ・比較対象・最速ラップのラベルとボックスを揃えました。
デスクトップでは同じ幅・48pxの高さで横一列になり、狭い画面では整列した状態で折り返します。
日本語・Englishと、1280・768・375px幅でレイアウトを確認しています。

**確認状況：** 開発PCで配布EXEの実ウィンドウを検証し、暗色ファイルメニュー、
37周、グラフ、メモ保存、言語切替、8ページ、両マニュアルが動作しました。
ソース版の確認と131件の回帰テストも成功しました。未署名のプレビューであり、
ノートPCとゲーム併用のチェックは必要です。以前の版はここでSmart App Controlに
拒否されており、別PCでも信頼ポリシーによってブロックされる場合があります。
App Controlの署名ポリシーはZIPのブロック解除では解消しません。

## 起動する

1. ZIPをPCにコピーします。展開前にZIPを右クリック → **プロパティ** →
   **許可する（ブロックの解除）** が表示されていればチェック → **適用**します。
   その後、**新しいフォルダーにすべて展開**してください。
2. 展開した `F1 Telemetry` フォルダーを開きます。
3. ゲームなしで試す場合は **過去ラップで試す.cmd** をダブルクリックします。
4. 自分の走行を記録する場合は **自分の走行を記録.cmd** または **F1 Telemetry.exe** を開きます。

`_internal` フォルダーはexeと一緒に置いてください。Pythonのインストールは不要です。
画面の表示にはMicrosoft Edge WebView2 Runtimeが必要です。見つからないと表示された場合は、
以下から **Evergreen Standalone Installer（x64）** をインストールしてください。

https://developer.microsoft.com/en-us/microsoft-edge/webview2/

このテスト版には電子署名がないため、Windowsで発行元不明の確認が出る場合があります。
作成者から受け取ったZIPを使用してください。

### `Failed to resolve Python.Runtime.Loader.Initialize` と表示された場合

Windowsがダウンロードしたファイルに付ける印によって、同梱DLLを読み込めなくなる
場合があります。同じ印を付けたテスト用コピーで、このエラーを再現し、
印を解除すると起動することを確認しました。

アプリを終了し、上の手順で元のZIPのブロックを解除してから、**新しいフォルダー**へ
展開し直してください。展開後にZIPだけを解除しても、すでに展開したファイルの印は残ります。
解除のチェックが表示されない場合や、展開し直しても同じエラーになる場合は、
`%LOCALAPPDATA%\F1Telemetry\logs\desktop.log` を共有して、詳しい原因を確認してください。

## 日本語／Englishを切り替える

各画面の上部にある **Language / 言語** で **日本語** または **English** を選択します。
ページを読み込み直さずに表示を切り替えます。選択中のセッション・ラップや、入力途中のメモは維持されます。
デスクトップ版では言語設定を保存し、次の起動時にも使用します。初回はWindowsの表示言語に合わせます。

ナビゲーション、操作ボタン、状態表示、グラフのラベル、分析の説明を切り替えます。
メモの内容、記録データ、ラップタイム、距離、単位は書き換えません。
画面上部の暗い **File / ファイル** メニューも、選択した言語で表示します。
白いメニューバーは表示しません。ウィンドウの移動・最小化・最大化・終了は通常どおり操作できます。

## 過去ラップのテストデータ

実際に走行して保存した37周を収録しています。理想的な走行を作った架空データではありません。
保存済みのテレメトリーとセットアップを含み、個人メモと古い分析キャッシュは含めていません。

| セッション | コース | 収録ラップ | 有効ラップ |
| --- | --- | ---: | ---: |
| 2026-08-25 フリー走行1 | バーレーン | 7周 | 5周 |
| 2026-08-14 レース | COTA | 22周 | 20周 |
| 2026-09-11 タイムトライアル | 不明なコース42 | 8周 | 1周 |

無効ラップは無効のまま、取得できなかった情報は不明のまま表示します。
コース42は現在のアプリでコース名を特定できていないため、「不明なコース42」と表示します。

**テストモードではゲームのUDPを受信しません。** 新しい走行記録とは別のコピーを使います。
テスト用のメモ・コーナー編集・分析は、そのコピーにだけ保存します。

## 確認してほしいこと

- 「テストラップ・記録停止中」と表示されること。
- セッションの選択で、3つのコースとそれぞれの周回数を確認できること。
- バーレーンで別の有効ラップを比較対象に選び、速度・入力・マップ・タイム差が表示されること。
- COTAでスティント分析と「ピット周回・無効ラップも含める」を確認できること。
- セッション分析を実行し、完了後に別ページへ移動して戻っても結果を確認できること。
- 日本語／Englishを切り替えてもラップの選択・数値・入力途中のメモが変わらないこと。
- テスト用メモを保存し、アプリを閉じて開き直すと、メモと言語設定が残っていること。
- ノートPCの画面サイズでボタンや項目が使いやすいこと。

データ不足の表示は、記録に必要な情報がない場合には正常です。
クラッシュ、読み込みが終わらない状態、誤ったラップの表示、翻訳の不自然な箇所があれば知らせてください。

## 自分の走行を記録する

以前のブラウザー版や別のテレメトリー受信アプリが動いている場合は、先に終了してください。
同じUDPポート20777を複数の受信アプリで同時に使うことはできません。

同じPCでゲームを動かす場合は、ゲームのUDP送信先を `127.0.0.1`、ポートを `20777` にします。
ゲームに合ったUDP形式を選んでください。別の機器から送信する場合は、PCのLAN内IPを送信先にし、
プライベートネットワークでのUDP受信を許可します。

1周を完了して次の周の開始ラインを越えると、完了したラップが保存されます。
アプリを閉じて開き直しても、その記録が残ることを確認してください。
走行途中の未完了ラップは、アプリを閉じただけでは保存されません。

## 保存先と困ったとき

保存先は `%LOCALAPPDATA%\F1Telemetry\` です。

- `sessions`：自分の新しい走行記録と分析。
- `test-laps-v1`：テスト用の過去ラップのコピー。
- `preferences.json`：日本語／Englishの設定。
- `logs\desktop.log`：起動やアプリのエラー。

**File / ファイル → 記録フォルダーを開く** または **ログフォルダーを開く** で確認できます。
exeのフォルダーを移動・更新しても、これらの記録は残ります。

テストデータを元に戻すには、アプリを閉じて `test-laps-v1` を別名に変更してバックアップします。
次のテスト起動で、元のデータをもう一度コピーします。

この版は開発PCで動作を確認済みです。別のPCでの互換性と、実際のゲーム受信を確認するためのテスト版です。
