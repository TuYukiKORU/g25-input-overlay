# 初回配布版のレビュー結果

対象：**v0.3.1 プレビュー／Windows 64bit**　確認日：2026年10月2日

開発PCで配布EXEを実際に起動して確認しました。友人向けのお試し版として配布できますが、ノートPCとゲーム併用での確認はまだ必要です。

## 修正した点

- ディスクへの保存に失敗した場合や、保存待ちが上限に達した場合に、画面へ「保存エラー」を表示するようにしました。終了時にも警告します。保存処理の例外で、その後の保存が止まる問題も対策しました。
- 別のWebサイトからアプリ内部への不適切なリクエストを減らすため、接続先と送信元の確認、データサイズ制限などを追加しました。PC内のすべてのソフトからのアクセスを認証する仕組みではありません。
- 予選・レース戦略には、比較可能な有効な **F1 26のラップが2周以上** 必要であることを明記しました。
- ダウンロードZIP、最初に読む案内、日本語マニュアルに、見つけやすい日本語名を付けました。依存ソフトのライセンス文書も同梱しました。

保存エラーは再起動まで表示されます。空き容量とフォルダーの書き込み権限を確認し、ログを調べてから再起動してください。失敗したラップや保存待ち上限で失われたラップは、自動では復元されません。

## 動作確認の結果

- 自動テスト **131件が成功**。保存失敗、保存待ち上限、外部リクエスト、送信サイズ制限も確認しました。
- 日本語と空白を含むフォルダーで、配布EXEの起動・再起動が成功しました。同じモードの二重起動とUDPポート使用中の案内も確認しました。
- 過去の **37周** を読み込み、4つのグラフを表示しました。言語変更で選択中のラップと入力中のメモが維持され、日本語設定と保存した日本語メモは再起動後も残りました。
- 日本語の8ページと、英語・日本語の各8章のマニュアルを確認しました。セッション分析と、COTAのF1 26ラップを使った予選・レース戦略分析が完了し、保存結果が最新になりました。
- テスト記録は通常の走行記録と分離されています。配布データ52ファイルの照合、ZIPの破損チェック、Windows 64bit形式の確認を行いました。実行ログ、個人メモ、古い分析キャッシュはテストデータに含めていません。

確認したEXEのSHA-256：`05b73e3ff2789c7e3103694b8338e6be6b4a6594010b8ab5ab1debfe3ad79da5`

## 友人に渡す前に知っておくこと

このEXEは**未署名のプレビュー**です。このPCでは起動しましたが、別のPCではWindowsの設定により起動できない場合があります。保護機能を無効にする方法は推奨しません。必要な環境では、信頼できる署名済み版を使用してください。

ノートPCでの実ゲーム録画、ゲームのFPSへの影響、GPU負荷は今回確認していません。同梱の負荷測定は、以前のv0.3.0をソースから起動したウィンドウでの測定であり、今回のEXEを新たに測定した数値ではありません。「はじめに.md」のチェックを実施してください。

戦略提案は記録データからの推定で、最適な戦略を保証するものではありません。条件不明や記録の欠損がある場合は比較の信頼度が下がります。

開発面では、ビルド用の依存ソフトを固定し、Windows上の自動ビルド・起動確認を整えることを推奨します。規模が大きくなったら、起動処理、画面の受付処理、分析処理の分離を進めると保守が容易になります。今回の確認はアプリの構造と動作のレビューであり、同梱される外部ソフト全体の正式な監査ではありません。

詳しい確認範囲は同梱の `RELEASE_REVIEW.md`、使い方は **使い方_日本語.html** を参照してください。
